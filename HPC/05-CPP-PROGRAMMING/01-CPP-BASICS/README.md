# Day 1 - C++ Basics & iostream

## Objective

- Write, compile, and run the first C++ program
- Understand the parts of a C++ program (headers, `main`, statements)
- Use `cout` for output, `cin` for input, `endl` for line breaks
- Compare C and C++ program structure

## What was done

- `hello_world.cpp` - first program
- `print_variables.cpp` - printing values with `cout`
- `input_output.cpp` - reading with `cin`, showing the result
- `add_two_numbers.cpp` - two-number sum with `cin`/`cout`

## Key differences from C (quick map)

| C | C++ |
| --- | --- |
| `#include <stdio.h>` | `#include <iostream>` |
| `printf()` / `scanf()` | `cout` / `cin` |
| `%d`, `%f` format specifiers | none - types are automatic |
| `int main()` + `return 0;` | same |
| compile with `gcc` | compile with `g++` |
