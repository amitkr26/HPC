# Day 1 - MCQ

Answers are on the line after each question (separated by a blank line).

**Q1. Which header must be included to use `cout` and `cin`?**
- A) `<stdio.h>`
- B) `<iostream>`
- C) `<string>`
- D) `<stdlib.h>`

Answer: B

**Q2. What does `using namespace std;` allow?**
- A) Using C functions without headers
- B) Using `cout`, `cin`, `endl` without the `std::` prefix
- C) Faster compilation
- D) Automatic memory management

Answer: B

**Q3. What is the output of: `cout << 5 + 2 << endl;`**
- A) `5 + 2`
- B) `52`
- C) `7`
- D) error

Answer: C

**Q4. Which operator extracts a value from `cin` into a variable?**
- A) `<<`
- B) `>>`
- C) `->`
- D) `:=`

Answer: B

**Q5. Which statement reads an integer into variable `x`?**
- A) `cin << x;`
- B) `cin >> x;`
- C) `x >> cin;`
- D) `scanf("%d", x);`

Answer: B

**Q6. What does `endl` do?**
- A) Ends the program
- B) Prints a newline and flushes output
- C) Deletes the last character
- D) Reads input

Answer: B

**Q7. Which file extension is standard for C++ source files?**
- A) `.c`
- B) `.cpp`
- C) `.exe`
- D) `.h`

Answer: B

**Q8. Which compiler is used to compile C++ programs in this course?**
- A) `gcc`
- B) `g++`
- C) `python`
- D) `javac`

Answer: B

**Q9. What is the output of:**

```cpp
int a = 10, b = 3;
cout << a / b;
```

- A) `3`
- B) `3.33`
- C) `10`
- D) `13`

Answer: A (integer division, same as C)

**Q10. `cout` with multiple `<<` pieces prints them...**
- A) in reverse order
- B) only the first one
- C) in the order written
- D) with commas between

Answer: C
