# Day 8: Structures and Unions

## Topics Covered
- struct keyword
- Declaring structures
- Accessing members (dot operator)
- Arrays of structures
- Structures as function arguments
- Pointers to structures (arrow operator ->)
- Nested structures
- typedef with structures
- unions

## Learning Objectives
1. Define and use structures
2. Create arrays of structures
3. Pass structures to functions
4. Use pointers with structures
5. Understand nested structures

## Prerequisites
- Functions (Day 6)
- Pointers (Day 5)
