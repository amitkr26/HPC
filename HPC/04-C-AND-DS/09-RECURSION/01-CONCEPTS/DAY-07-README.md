# Day 7: Recursion

## Topics Covered
- What is recursion?
- Base case and recursive case
- Tail recursion
- Head recursion
- Factorial using recursion
- Fibonacci using recursion
- Tower of Hanoi
- Array traversal using recursion
- String reversal using recursion

## Learning Objectives
1. Understand the concept of recursion
2. Identify base case and recursive case
3. Convert iterative solutions to recursive ones
4. Understand stack behavior in recursion
5. Recognize when recursion is appropriate

## Prerequisites
- Functions (Day 6)
- Basic C syntax
