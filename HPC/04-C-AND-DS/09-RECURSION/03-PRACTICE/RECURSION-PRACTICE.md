# Practice: Recursion

## Beginner
1. Write a recursive function to find factorial
2. Write a recursive function for Fibonacci series
3. Write a recursive function to find power
4. Write a recursive function to find sum of digits
5. Write a recursive function to print numbers 1 to N

## Intermediate
6. Write a recursive function to reverse a number
7. Write a recursive function to check palindrome
8. Write a recursive function to find GCD
9. Write a recursive function to print array elements
10. Write a recursive function to find the largest in an array

## Advanced
11. Write Tower of Hanoi solution
12. Write recursive binary search
13. Write recursive bubble sort
14. Write recursive string reversal
15. Write recursive function to convert decimal to binary
