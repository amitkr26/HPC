## How to use

1. Pick a question. Write the program in `01-BEGINNER/Day-01/code/` (create
   the folder, or use any folder you like).
2. Compile: `C:\MinGW\bin\gcc.exe <file.c> -o <file.exe>`
3. Compare your approach with the solved program listed in the table.
4. Update confidence in `02-PROGRESS.md` when the batch is done.
