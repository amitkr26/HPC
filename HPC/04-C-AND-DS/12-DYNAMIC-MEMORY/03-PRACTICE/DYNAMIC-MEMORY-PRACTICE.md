# Practice: Dynamic Memory

## Beginner
1. Allocate an array of N integers using malloc, fill and print
2. Allocate an array using calloc, verify all zeros
3. Use realloc to resize an array from 5 to 10 elements
4. Allocate a structure dynamically, fill and print
5. Free allocated memory and verify no leaks

## Intermediate
6. Create a dynamic array of structures (students)
7. Create a dynamic 2D array and fill with user input
8. Reallocate a string to make it longer
9. Create a dynamic array, sort it, then free
10. Create a dynamic array of characters (string)

## Advanced
11. Implement a dynamic stack using malloc/realloc
12. Implement a dynamic queue
13. Create a jagged 2D array (different row sizes)
14. Write a function that returns a dynamically allocated array
15. Write a program to detect memory leaks
