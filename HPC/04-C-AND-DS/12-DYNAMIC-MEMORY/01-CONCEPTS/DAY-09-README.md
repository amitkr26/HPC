# Day 9: Dynamic Memory Allocation

## Topics Covered
- Why dynamic memory?
- malloc() - allocate memory
- calloc() - allocate and initialize
- realloc() - resize allocation
- free() - release memory
- Memory leaks
- Dynamic arrays
- Dynamic structures

## Learning Objectives
1. Allocate memory at runtime
2. Use malloc, calloc, realloc, free correctly
3. Avoid memory leaks
4. Create dynamic arrays of any size
5. Understand heap vs stack

## Prerequisites
- Pointers (Day 5)
- Structures (Day 8)
