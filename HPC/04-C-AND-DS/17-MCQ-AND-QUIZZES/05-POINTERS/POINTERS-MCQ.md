# MCQ: Pointers

1. What does a pointer store?
   - A) A value
   - B) A memory address
   - C) A data type
   - D) A function

2. Which operator is used to get the address of a variable?
   - A) *
   - B) &
   - C) #
   - D) %

3. Which operator is used to access the value at a pointer address?
   - A) &
   - B) ->
   - C) *
   - D) .

4. What is a NULL pointer?
   - A) A pointer pointing to 0
   - B) A pointer that points to nothing
   - C) A pointer to void
   - D) An uninitialized pointer

5. What is the output of: int x=5; int *p=&x; printf("%d", *p);
   - A) 5
   - B) Address of x
   - C) 0
   - D) Error

6. What does ptr++ do in pointer arithmetic?
   - A) Adds 1 byte
   - B) Adds sizeof(type) bytes
   - C) Subtracts sizeof(type) bytes
   - D) Nothing

7. What is a double pointer?
   - A) A pointer with two stars
   - B) A pointer that stores address of another pointer
   - C) A pointer to two variables
   - D) Two pointer variables

8. Which is correct for passing a variable by reference?
   - A) func(x)
   - B) func(&x)
   - C) func(*x)
   - D) func(x*)

9. What is the relationship between arr and &arr[0]?
   - A) They are different
   - B) arr == &arr[0]
   - C) arr > &arr[0]
   - D) arr < &arr[0]

10. What happens if you dereference a NULL pointer?
    - A) Returns 0
    - B) Program crashes (undefined behavior)
    - C) Returns NULL
    - D) Returns -1

### Answers
1-B, 2-B, 3-C, 4-B, 5-A, 6-B, 7-B, 8-B, 9-B, 10-B
