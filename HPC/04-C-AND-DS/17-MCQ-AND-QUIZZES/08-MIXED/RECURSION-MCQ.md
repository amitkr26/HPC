# MCQ: Recursion

1. What is the base case in recursion?
   - A) When function is called
   - B) When function stops calling itself
   - C) When function returns void
   - D) When variable is null

2. What happens without a base case?
   - A) Normal execution
   - B) Infinite recursion (stack overflow)
   - C) Compilation error
   - D) Returns 0

3. What is tail recursion?
   - A) Recursive call at the beginning
   - B) Recursive call is the last operation
   - C) No base case
   - D) Multiple recursive calls

4. What is the output of factorial(0)?
   - A) 0
   - B) 1
   - C) Error
   - D) Undefined

5. Which uses more memory?
   - A) Iteration
   - B) Recursion
   - C) Same
   - D) Depends

6. What is the 7th Fibonacci number (fib(6))?
   - A) 5
   - B) 8
   - C) 13
   - D) 21

7. What data structure does recursion use internally?
   - A) Queue
   - B) Stack
   - C) Array
   - D) Linked list

8. What is indirect recursion?
   - A) Function calls itself
   - B) A calls B, B calls A
   - C) No recursion
   - D) Nested functions

9. What is the time complexity of recursive Fibonacci?
   - A) O(n)
   - B) O(n^2)
   - C) O(2^n)
   - D) O(log n)

10. When should you prefer iteration over recursion?
    - A) Always
    - B) When performance is critical
    - C) Never
    - D) Only for trees

### Answers
1-B, 2-B, 3-B, 4-B, 5-B, 6-B, 7-B, 8-B, 9-C, 10-B
