# Practice: Pointers

## Beginner
1. Write a program to swap two numbers using pointers
2. Write a program to find the sum of two numbers using a function with pointer arguments
3. Write a program to print array elements using pointer arithmetic
4. Write a program to reverse an array using pointers
5. Write a program to find the largest element using a pointer

## Intermediate
6. Write a function that returns multiple values (min, max) using pointers
7. Write a program using double pointers to modify a variable
8. Write a program to count even and odd numbers in an array using pointers
9. Write a program to traverse a string using pointer arithmetic
10. Write a program to find the sum of array elements using pointer

## Advanced
11. Write a function that sorts an array using pointers (bubble sort)
12. Write a program to concatenate two strings using pointers (no strcat)
13. Write a program to compare two strings using pointers (no strcmp)
14. Write a program using void pointer to handle different data types
15. Write a program to find the second largest element using pointers
