# Day 6: Functions

## Topics Covered
- What is a function?
- Function declaration (prototype)
- Function definition
- Function call
- Parameters and arguments
- Return values
- Call by value vs call by reference
- Recursive functions
- Storage classes (auto, static, extern, register)

## Learning Objectives
1. Write and call functions correctly
2. Understand function prototypes
3. Pass arguments by value and by reference
4. Return values from functions
5. Understand scope and lifetime of variables

## Prerequisites
- C Fundamentals (Day 1)
- Variables and Data Types
- Pointers (Day 5)
