# Practice: Functions

## Beginner
1. Write a function to add two numbers
2. Write a function to check if a number is prime
3. Write a function to find the factorial of a number
4. Write a function to print the Fibonacci series
5. Write a function to swap two numbers (call by value and reference)

## Intermediate
6. Write a function to find the GCD of two numbers
7. Write a function to check if a number is palindrome
8. Write a function to reverse a number
9. Write a function to find the power of a number (without pow)
10. Write a function to convert temperature (Celsius to Fahrenheit)

## Advanced
11. Write a recursive function to find the sum of digits
12. Write a recursive function to print array in reverse
13. Write a function that sorts an array (bubble sort)
14. Write a function that searches an element (linear search)
15. Write a function to check if a string is palindrome
