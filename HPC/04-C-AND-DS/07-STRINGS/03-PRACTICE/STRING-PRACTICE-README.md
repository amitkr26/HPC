# String Practice

Practice drills for strings. Full detail: `../PRACTICE.md` (levels 1-6) and
`../REVISION.md` (revision sets). New practice programs go in `code/`.

## Quick drills (do these from memory)

1. Reverse a string and print it.
2. Count how many times a given character appears in a string.
3. Convert a string to uppercase (without `toupper` loop? with it).
4. Check whether a string is a palindrome.
5. Remove spaces from a string.
6. Check whether one string is a substring of another (use `strstr` - new).
7. Capitalize the first letter of every word.
8. Compare two strings case-insensitively.
9. Extract the vowels into a second array.
10. Count words in a sentence.
