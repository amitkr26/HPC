## Study flow

1. `COURSE.md` (this file) = the schedule of record.
2. Per-module `README.md` = module card + folder layout.
3. `ASSIGNMENT-MAPPING.md` = which assignment document maps to which
   solution program (C, C++, Linux, Python covered).
4. `99-REFERENCES/` = the source PDF + review archive.
5. `bdw-llm/` = the standalone from-scratch LLM project on PARAM Rudra
   (not a course module; see its own README + docs).
