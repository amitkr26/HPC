# Data Handling Practice

These scripts are the NumPy/pandas practice set for Module 10. They were
previously loose files at the repository/module root and are indexed here by
topic.

| Script | Topic |
|--------|-------|
| `01_numpy_array_basics.py` | 1D/2D/3D array creation and reshaping |
| `02_numpy_indexing.py` | scalar, row and column indexing |
| `03_numpy_array_creation.py` | `arange`, `reshape`, shape checks |
| `04_numpy_slicing.py` | 1D/2D slicing and negative steps |
| `05_pandas_read_csv_export.py` | read remote CSVs, preview, JSON export |
| `06_pandas_iris_subset.py` | select columns from the Iris dataset |
| `07_pandas_titanic_filter.py` | boolean filtering on Titanic fares |
| `08_pandas_iris_filter.py` | filter Iris rows by sepal length |
| `09_pandas_tips_filter.py` | filter tips by value and meal time |
| `10_pandas_loc_iloc.py` | `.loc`/`.iloc` on the Titanic dataset |
| `11_pandas_mtcars_loc_iloc.py` | label and position indexing on mtcars |

`05_pandas_read_csv_export.py` generates `export.json` in this directory. The
other pandas scripts download their CSV inputs from public GitHub URLs, so an
internet connection and `pandas` are required.

These are raw practice files retained as written; a few are incomplete
snippets rather than polished programs.
