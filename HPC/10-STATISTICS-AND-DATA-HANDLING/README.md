## Practice set

The practice scripts cover the two libraries used through the module:

- **NumPy (01–04):** array creation, indexing, reshaping and slicing.
- **pandas (05–11):** loading public CSV datasets, column selection,
  boolean filtering, and `.loc`/`.iloc` indexing.
- `05_pandas_read_csv_export.py` writes `export.json`; the remaining pandas
  scripts read their datasets directly from public URLs.

The files are preserved as written during practice; some (for example the
NumPy array-creation snippets) are intentionally short or incomplete.

Run an individual script from `01-DATA-HANDLING-PRACTICE/`:

```bash
cd 01-DATA-HANDLING-PRACTICE
python 10_pandas_loc_iloc.py
```

See [`01-DATA-HANDLING-PRACTICE/README.md`](01-DATA-HANDLING-PRACTICE/README.md)
for the per-script index.
