# C++ Course Roadmap

Learning progression for C++, assuming the completed C course as foundation.

## Phase 1: C++ Fundamentals

### Day 1: Basics & iostream (CURRENT)
- Program structure, `#include <iostream>`, `main()`
- `cout`, `cin`, `endl`, `using namespace std`
- Compilation with g++
- **Location**: `01-CPP-BASICS/Day-01/`

### Day 2: Variables, Data Types & Operators
- C++ data types, `sizeof`, type modifiers
- Arithmetic, relational, logical operators
- Type conversion (implicit/explicit casts)

### Day 3: Control Flow
- `if/else`, `switch`, loops (`for`, `while`, `do-while`)
- `break`, `continue`

### Day 4: Functions (C++ style)
- Default arguments, function overloading, inline functions
- Reference parameters (`&`)

## Phase 2: Object-Oriented Programming

### Day 5: Classes & Objects
- `class`, `public`/`private`, constructors/destructors
- Member functions, `this` pointer

### Day 6: OOP Advanced
- Function overloading, operator overloading
- `friend` functions, static members

### Day 7: Inheritance & Polymorphism
- Base/derived classes, `virtual` functions, abstract classes

## Phase 3: C++ Standard Library

### Day 8: Strings & STL
- `std::string`, `vector`, `map`, iterators
