# C Programs

Practice programs written in C covering basic to intermediate concepts.

## Topics

- Basic I/O (`hello.c`, `test.c`, `test2.c`, `test3.c`, `test4.c`)
- Arithmetic and operators (`opera.c`, `operator.c`, `operators.c`, `unary.c`, `typecast.c`, `swap.c`)
- Decision making (`age.c`, `vote.c`, `leap.c`, `leaps.c`, `nestedif.c`, `nest.c`, `even.c`, `hot.c`)
- Loops (`loop.c`, `numbers.c`, `num.c`)
- Number systems and logic (`binary.c`, `bin.c`)
- Geometry (`area.c`, `circle.c`, `circlecir.c`, `div.c`)

## Building

Compile any program with:

```bash
gcc <filename>.c -o <filename>
```
