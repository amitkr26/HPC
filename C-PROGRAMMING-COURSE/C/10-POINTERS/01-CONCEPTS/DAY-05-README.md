# Day 5: Pointers

## Topics Covered
- What is a pointer?
- Pointer declaration and initialization
- Address-of operator (&) and dereference operator (*)
- Pointer arithmetic
- Pointers and arrays
- Pointers as function arguments (call by reference)
- Double pointers
- NULL pointer
- void pointer

## Learning Objectives
1. Understand how memory addresses work
2. Declare and use pointers correctly
3. Perform pointer arithmetic
4. Pass variables by reference to functions
5. Use double pointers

## Prerequisites
- C Fundamentals (Day 1)
- Variables and Data Types
- Basic I/O with printf/scanf
