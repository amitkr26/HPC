# Day 10: File Handling

## Topics Covered
- File pointers (FILE*)
- Opening and closing files (fopen, fclose)
- File modes (r, w, a, r+, w+, a+)
- Reading characters (fgetc, fgets)
- Writing characters (fputc, fputs)
- Formatted I/O (fprintf, fscanf)
- Random access (fseek, ftell, rewind)
- Error handling (feof, ferror)

## Learning Objectives
1. Open and close files correctly
2. Read and write text files
3. Use different file modes
4. Perform formatted file I/O
5. Handle file errors

## Prerequisites
- Basic C I/O (printf, scanf)
- Functions (Day 6)
- Strings (Day 4)
