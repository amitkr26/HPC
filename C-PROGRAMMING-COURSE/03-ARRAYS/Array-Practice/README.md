# Array Practice

Practice drills for arrays. Full detail: `../PRACTICE.md` (levels 1-6) and
`../REVISION.md` (revision sets). This folder also holds any new practice
programs you write (`code/`).

## Quick drills (do these from memory)

1. Read 5 numbers, print their sum and average.
2. Find the second largest element.
3. Count positive, negative, and zero elements.
4. Check if an array is sorted (ascending).
5. Print only elements at even indices.
6. Merge two sorted arrays.
7. Remove all duplicate values.
8. Rotate the array left by one position.
9. Given two arrays, count how many positions differ.
10. Find the most frequent value.

Answers/working programs: write them yourself in `code/` before looking at
`C/Arrays/` programs.
