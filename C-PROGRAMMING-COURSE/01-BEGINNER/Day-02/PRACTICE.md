## How to use

1. Rewrite each program from memory in `01-BEGINNER/Day-02/code/` (create the
   folder, or use any folder you like).
2. Compile: `C:\MinGW\bin\gcc.exe <file.c> -o <file.exe>`
3. Compare with the solved program in `C/Day2/`.
4. Update confidence in `02-PROGRESS.md` when the batch is done.

- `break` / `continue` in real loops (only conceptual questions done so far).
- Ternary operator (used in the question bank, not yet written as a program).
- Explain out loud: for vs while vs do-while, entry vs exit controlled loops,
  what switch cannot do, `case` label requirements (all in `C/Day2/Amit_Lab2.md`).
