# Variables

## What it is

A named memory location whose value can change. Name = identifier; the rules
are: letters/digits/underscore, must not start with a digit, no spaces, no
keywords, case-sensitive.

## Common mistakes

- `int float = 5;` -> `float` is a keyword. Use another name.
- `1student` as a name -> must not start with a digit.
- `student name` -> spaces not allowed.
