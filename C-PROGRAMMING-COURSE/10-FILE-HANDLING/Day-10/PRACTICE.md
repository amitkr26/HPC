# Practice: File Handling

## Beginner
1. Write a program to create a text file and write your name
2. Write a program to read a text file and print its content
3. Write a program to append a line to an existing file
4. Write a program to count characters in a file
5. Write a program to copy content from one file to another

## Intermediate
6. Write a program to count words in a file
7. Write a program to count lines in a file
8. Write a program to convert file content to uppercase
9. Write a program to merge two files into a third
10. Write a program to find a word in a file

## Advanced
11. Write a student record system using file I/O
12. Write a program to encrypt/decrypt a file
13. Write a program to sort lines in a file
14. Write a program to remove duplicate lines from a file
15. Write a program to search and replace text in a file
