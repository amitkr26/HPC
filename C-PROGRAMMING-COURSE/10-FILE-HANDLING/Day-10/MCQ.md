# MCQ: File Handling

1. Which header is needed for file handling?
   - A) stdlib.h
   - B) stdio.h
   - C) string.h
   - D) math.h

2. What does fopen return if file doesn't exist (mode "r")?
   - A) 0
   - B) NULL
   - C) -1
   - D) Garbage

3. Which mode creates a new file?
   - A) r
   - B) w
   - C) r+
   - D) a

4. What does fgetc return at end of file?
   - A) NULL
   - B) 0
   - C) EOF
   - D) -1

5. Which function reads a line from file?
   - A) fgetc
   - B) fgets
   - C) fscanf
   - D) fread

6. Which function writes formatted output to file?
   - A) printf
   - B) fprintf
   - C) sprintf
   - D) fputs

7. What is the difference between "w" and "a"?
   - A) No difference
   - B) "w" truncates, "a" appends
   - C) "w" is faster
   - D) "a" is faster

8. What does fseek(fp, 0, SEEK_SET) do?
   - A) Go to end
   - B) Go to beginning
   - C) Go to middle
   - D) Close file

9. What does ftell return?
   - A) File size
   - B) Current position
   - C) Beginning
   - D) End

10. Why close files?
    - A) Required by C
    - B) Free resources
    - C) Save data
    - D) All of above

### Answers
1-B, 2-B, 3-B, 4-C, 5-B, 6-B, 7-B, 8-B, 9-B, 10-D
