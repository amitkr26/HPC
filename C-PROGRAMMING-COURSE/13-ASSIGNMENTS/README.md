## Deliverable format

The exact format used for solved documents is documented in `AGENTS.md`
(`## C Assignment Deliverable Format`): clone
`Amit_Kumar_Lab4_Day4_Assignment.docx`, swap in code tables and screenshots,
keep the MCQ answers table and Explain section.

## When a new assignment arrives

1. Put the problem sheet in `C/Assignmenmt/`.
2. Create the per-question programs in the matching `C/DayN/` folder.
3. Build the solved document in the AGENTS.md format.
4. Update this index and `02-PROGRESS.md`.
