# Practice: Structures and Unions

## Beginner
1. Define a struct Student and print its members
2. Create an array of 5 students and print all
3. Write a function to accept a student's details
4. Write a function to display a student's details
5. Find the student with the highest marks

## Intermediate
6. Write a program using nested structures (Date inside Student)
7. Write a function that sorts students by marks
8. Write a program using pointer to structure
9. Write a typedef struct for a Point (x, y) and find distance
10. Write a program using union to demonstrate shared memory

## Advanced
11. Write a student management system (add, search, display, delete)
12. Write an employee management system with departments
13. Write a library management system using structures
14. Write a program to compare two structures
15. Write a program to copy one structure to another
